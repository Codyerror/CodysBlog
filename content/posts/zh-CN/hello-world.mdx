## 为什么开这个本子

同一个问题我老是修两遍。不是因为难，是三个月后完全想不起当时的自己在干嘛，只能把同一条报错再搜一次。

所以这就是个笔记本。想明白一件事，趁还没忘赶紧写下来。没有选题日历，也没有什么宏大计划。

Mochi 现在正趴在笔记本最暖的那块地方，用睡着的方式表示同意。

## 这儿会写什么

数据分析为主，机器学习一点，还有那些每次重新想起来都要花掉我半天、说出去有点丢人的工程小细节。半年后如果能帮我省二十分钟，这篇就算没白写。

## 这站是怎么跑的

就是文件。每篇文章都是 `content/posts/` 下的一个 `.mdx`。没有数据库，没有 CMS，也没有要登录的后台。

```bash
npm run new:post -- --slug my-second-post --title "第二篇文章"
git add . && git commit -m "post: 第二篇" && git push
```

站点重新构建，归档、标签页、RSS、sitemap 全都自己跟着变。整个流程就这么点。

```python
def future_me():
    return "谢了，大概"

print(future_me())
```
