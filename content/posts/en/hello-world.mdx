## How the site works

It's just files. Every post is a `.mdx` file in `content/posts/`. No database, no CMS, no admin panel to log into.

```bash
npm run new:post -- --slug my-second-post --title "My second post"
git add . && git commit -m "post: second one" && git push
```

The site rebuilds, and the archive, tag pages, RSS feed and sitemap all update themselves. That's the whole workflow.
